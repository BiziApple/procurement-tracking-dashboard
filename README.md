# Procurement Tracking Dashboard

## Overview
This repository contains a professional procurement tracking dashboard portfolio project designed for tender monitoring, supplier management, procurement status tracking, and budget analysis.

## Project Objectives
- Improve procurement visibility
- Track tender status
- Monitor supplier performance
- Support budget control
- Strengthen reporting and transparency

## Key Features
- Tender tracking
- Supplier database
- Budget monitoring
- Procurement reporting
- Dashboard screenshots
- Sample datasets

## Repository Structure
- `Dashboard/` - dashboard requirements and design documentation
- `Supplier-Database/` - supplier database samples
- `Tender-Tracking/` - tender tracking reports
- `Budget-Monitoring/` - budget monitoring analysis
- `Reports/` - procurement status reports
- `Screenshots/` - dashboard screenshots
- `Data/` - sample datasets

## Tools Used
- Microsoft Excel
- Power BI / Dashboard Concepts
- GitHub
- Word Documentation
- CSV Data Files
